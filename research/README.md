# 逆向分析材料

存放汽水音乐（SodaMusic）PC 客户端逆向提取物，**不要放进 `logs/`**。

| 目录 | 内容 |
|------|------|
| `sodamusic-asar-extract/` | asar 解包、sourcemap、IDL 契约、接口清单 JSON |
| `sodamusic-asar-tools/` | `@electron/asar` 等解包依赖 |
| `extract-scripts/` | 扫描/提取脚本 |

接口文档见：`docs/汽水音乐API接口文档/`、`docs/汽水音乐随机播放机制.md`。

> 材料仅供本项目学习研究使用。
