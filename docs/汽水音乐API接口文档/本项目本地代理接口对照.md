# 本项目本地代理接口对照

说明 SodaMusic-Download 本地 Express 服务 `/api/*` 的职责，以及与汽水音乐上游接口的映射关系。

默认监听：`http://localhost:3001`（`PORT` 可覆盖）。前端静态资源从 `dist/` 提供。

路由注册：`server/apis/index.js` → `server/index.js`。

---

## 一、路由总表

| Method | 本地 Path | 上游 / 本地能力 | 鉴权输入 | 备注 |
|--------|-----------|-----------------|----------|------|
| GET | `/api/health` | 无上游 | 无 | 存活探测 |
| GET | `/api/auth/qrcode` | `GET /passport/web/get_qrcode/` | 无 | 扫码二维码 |
| POST | `/api/auth/qrcode/status` | `POST /passport/web/check_qrconnect/` | 无 | 轮询 + 抽 sessionid |
| GET | `/api/auth/one-click-support` | 本机 Cookies SQLite | 无 | 探测/读取 sessionid |
| POST | `/api/auth/file-login-support` | 上传 Cookies 文件解析 | 无 | base64 → sessionid |
| GET | `/api/auth/auto-login` | 本机 Cookies + `GET /luna/pc/me` | 无 | 静默自动登录；非 Windows skip；前端启动未登录时静默调用 1 次 |
| POST | `/api/auth/profile` | `GET /luna/pc/me` | body.sessionid | 当前用户资料 |
| POST | `/api/me/playlists` | `GET /luna/pc/me/playlist` | body.sessionid | 自建歌单列表 |
| POST | `/api/me/collection/mixed` | `GET /luna/pc/me/collection/mixed` | body.sessionid | 混合收藏 |
| POST | `/api/playlist/detail` | `GET /luna/pc/playlist/detail` | body.sessionid + playlist_id | 歌单分页曲目 |
| POST | `/api/playlist/batch-download` | track_v2/视频下载/打包 ZIP | body.sessionid + tasks | 本地编排，非单一上游 |
| GET | `/api/playlist/batch-progress` | 本地内存进度 | query.batch_id | 轮询进度 |
| POST | `/api/track/v2` | `POST /luna/pc/track_v2` | body.sessionid + track_id | **需 BDMS** |
| POST | `/api/track/download-encrypted` | track_v2 + 媒体 URL + 解密 | body.sessionid + track_id + quality | 返回音频附件 |
| POST | `/api/video/v2` | `POST /luna/pc/video_v2` | body.sessionid + video_id | 视频元数据 |
| POST | `/api/video/download` | 媒体直链流式转发 | body.url | 不经过 qishui 业务 API |
| POST | `/api/video/download-audio` | 媒体直链抽音频 | body.url | 返回音频附件 |
| POST | `/api/share/resolve` | 分享落地页 HTML 抓取 | body.share_text / url | 非 goapi 分享接口 |
| GET | `/api/system/logs` | 本地日志文件 | query.lines? | 调试 |

## 二、上游映射细节

### 2.1 配置来源

`server/config/qishui-auth.js`：

| 项 | 值 |
|----|-----|
| baseUrl | `https://api.qishui.com` |
| aid | `386088` |
| app_name | `luna_pc` |
| version_name / code | `3.7.0` / `30070000` |
| region 族 | `cn` |
| device_platform / type | `windows` / `Windows` |
| 其它 | passport_jssdk_version、iid、channel、build_mode、ac、tz_name |

`getPcQuery(overrides)` 组装业务请求公共 query。

### 2.2 认证

| 本地 | 上游 query / body | 响应使用字段 |
|------|-------------------|--------------|
| `GET /api/auth/qrcode` | passport jssdk 固定 query | `data.token`、`data.qrcode`、`data.expire_time` |
| `POST /api/auth/qrcode/status` | form：token + passport 固定字段 | `data.status` + `auth.sessionid`（Set-Cookie 抽取） |
| `POST /api/auth/profile` | `aid` | `status_code`、`my_info` |
| one-click / file-login / auto-login | 本机或上传 SQLite | `sessionid` |

### 2.3 列表与歌单

| 本地 | 上游 | 本地 body | 使用的上游响应字段 |
|------|------|-----------|--------------------|
| `/api/me/playlists` | `/luna/pc/me/playlist` + getPcQuery | sessionid, aid? | `playlists[]`、`total_num`、`status_code` |
| `/api/me/collection/mixed` | `/luna/pc/me/collection/mixed` + aid | sessionid, aid? | `mixed_collections[]`、`total_num` |
| `/api/playlist/detail` | `/luna/pc/playlist/detail` + getPcQuery | sessionid, playlist_id, cursor, count | `playlist`、`media_resources[]`、`has_more`、`next_cursor` |

### 2.4 曲目与视频

| 本地 | 上游 | 请求头要点 |
|------|------|------------|
| `POST /api/track/v2` | `/luna/pc/track_v2` | Cookie + Content-Type + UA LunaPC + X-Helios/X-Medusa |
| `POST /api/track/download-encrypted` | 同上 + GET `video_list[].main_url` | 媒体 UA：`libcurl-agent/1.0` |
| `POST /api/video/v2` | `/luna/pc/video_v2` | Cookie + Content-Type + UA LunaPC（当前实现未加 BDMS） |
| `POST /api/video/download` | 媒体 URL 直链 | 流式，带超时与 idle 检测 |
| `POST /api/video/download-audio` | 媒体 URL 直链 | 本地抽取音频 |

track_v2 上游 body：

```json
{
  "track_id": "<id>",
  "media_type": "track",
  "queue_type": "search_one_track",
  "scene_name": "search"
}
```

download-encrypted 额外需要 `quality`：具体品质字符串，或 `highest` / `lowest`（按 `video_meta.size` 排序）。

### 2.5 分享解析（无直接 goapi 对照）

`POST /api/share/resolve`：

1. 从 `share_text`/`url` 提取 http(s) URL；
2. GET 落地页（30s 超时，HTML 上限 5MB）；
3. 从 URL path/query 或 HTML 正则提取 `track_id` / `video_id`；
4. 返回 `{ resource_type, track_id, video_id, final_url, share_url }`。

上游存在但本项目未使用：

| Path | 用途 |
|------|------|
| `GET /luna/share/code/parse` | token → schema/文案 |
| `GET /luna/query_zlink` | token → info |
| `GET /luna/pc/share_info` | item_type/item_id → share_info |

### 2.6 纯本地接口

| Path | 说明 |
|------|------|
| `/api/health` | message + port + author 字段 |
| `/api/playlist/batch-download` | 按 tasks 下载/解密/打包；进度写入 batch-progress-store |
| `/api/playlist/batch-progress` | `batch_id` 查询 total/completed/status/error |
| `/api/system/logs` | 读取日志文件末尾 N 行 |

## 三、通用请求约定

### 3.1 需要 sessionid 的代理

多数业务代理 body：

```json
{
  "aid": "386088",
  "sessionid": "<from login>"
}
```

缺失时返回 HTTP 400：`sessionid is required`。

歌单详情额外：`playlist_id` 必填；`cursor` 默认空；`count` 默认 15。

track/video 额外：`track_id` / `video_id` 必填。

### 3.2 上游错误处理模式

本项目代理统一：

1. `fetchWithTimeout`（默认 30s；下载类更长）；
2. `upstream.text()` 后再 `JSON.parse`；
3. 非 JSON 时返回 `_raw` 预览，避免裸抛；
4. `status_code !== 0` 时业务层报错（见 track-download）；
5. 日志记录 method/path/status/elapsed。

### 3.3 平台

`server/index.js` 非 win32 直接 exit，原因：bdms.node 依赖 Windows 原生模块。

## 四、典型调用链

### 4.1 扫码登录 → 下载单曲

```
GET  /api/auth/qrcode
POST /api/auth/qrcode/status     → sessionid
POST /api/auth/profile           → 校验 my_info
POST /api/track/v2               → track + track_player.video_model
POST /api/track/download-encrypted { sessionid, track_id, quality }
     → 解密后的音频附件
```

### 4.2 一键登录 → 歌单批量下载

```
GET  /api/auth/one-click-support → sessionid
POST /api/me/playlists           → 选歌单 id
POST /api/playlist/detail        → 分页 media_resources
POST /api/playlist/batch-download { sessionid, tasks[], batch_id? }
GET  /api/playlist/batch-progress?batch_id=...
```

### 4.3 分享链接

```
POST /api/share/resolve          → track_id 或 video_id
POST /api/track/v2 或 /api/video/v2
POST /api/track/download-encrypted 或 /api/video/download
```
