# 认证与登录接口

说明汽水音乐 PC 的扫码登录、会话心跳、SSO 与本机 Cookies 免扫码登录路径，以及本项目本地代理如何对接。

---

## 一、接口总表

| Method | Path | 用途 | 鉴权 | 备注 |
|--------|------|------|------|------|
| GET | `/passport/web/get_qrcode/` | 获取扫码登录 token 与二维码图 | 无 | 本项目已对接 |
| POST | `/passport/web/check_qrconnect/` | 轮询扫码状态，成功时下发 Set-Cookie | 无 | body 为 form；本项目已对接 |
| GET | `/passport/token/beat/web/` | 登录态 token 心跳 | Cookie + BDTicket | 零信任加签白名单路径 |
| GET | `/luna/sso/token` | SSO 换取 auth_token | query: code/state/device_id | 契约见 sso.ts |
| GET | `/luna/token/user/info` | 按 token 查询用户信息 | query: token | 与 passport token 配合 |
| GET | `/luna/device/recent-login` | 本机最近登录账号 | 设备上下文 | 返回 `user_basic` |
| GET | `/luna/pc/me` | 校验登录态 / 拉取当前用户 | Cookie | 登录后主验证接口 |
| GET | `/luna/pc/launch` | PC 启动初始化 | Cookie 可选 | 返回 device_status 等 |
| POST | `/luna/log/event` | 事件上报（含登录相关） | Cookie 可选 | event_key/details |
| POST | `/luna/me/report_special_id` | 上报登录/登出 SID | Cookie | action: login=0 / signout=1 |

客户端登出：`UserService.logout()` 调用渲染进程 `callLoginSdkLogout()`，并清空本地用户缓存。goapi 表中未出现独立的 `/logout` 业务 path；登出走 passport/登录 SDK 侧。

## 二、扫码登录流程

### 2.1 获取二维码

**上游**：`GET https://api.qishui.com/passport/web/get_qrcode/`

**query**（本项目 `server/config/qishui-auth.js`）：

| 参数 | 值 |
|------|-----|
| `passport_jssdk_version` | `2.4.13` |
| `passport_jssdk_type` | `normal` |
| `is_from_ttaccountsdk` | `1` |
| `aid` | `386088` |
| `next` | `https://api.qishui.com` |

**响应关键字段**（本项目代理返回结构）：

| 字段 | 类型 | 含义 |
|------|------|------|
| `data.token` | string | 轮询用一次性 token |
| `data.qrcode` | string | `data:image/png;base64,...` 二维码图 |
| `data.expire_time` | number | 过期时间 |
| `data.qrcode_index_url` | string | 二维码关联页 |

**本项目代理**：`GET /api/auth/qrcode`

---

### 2.2 轮询扫码状态

**上游**：`POST https://api.qishui.com/passport/web/check_qrconnect/`

**query**：`passport_jssdk_version`、`passport_jssdk_type`、`is_from_ttaccountsdk`、`aid`、`iid`

**请求头**：`content-type: application/x-www-form-urlencoded`

**form body**：

| 字段 | 说明 |
|------|------|
| `token` | 上一步返回的 token |
| `need_logo` | `false` |
| `need_short_url` | `false` |
| `is_frontier` | `true` |
| `is_new_login` | `1` |
| `next` | `https://api.qishui.com` |

**状态语义**（本项目代理文档字段）：

| data.status | 含义 |
|-------------|------|
| `new` | 已创建，待扫码 |
| `scanned` | 已扫码，待确认 |
| `confirmed` | 已确认登录 |

**会话下发**：确认后上游 `Set-Cookie` 含 `sessionid`（域 `.qishui.com`）。本项目从响应头抽取后放进响应体 `auth.sessionid`。

**本项目代理**：`POST /api/auth/qrcode/status`，body `{ token }`

---

### 2.3 登录态校验

**上游**：`GET https://api.qishui.com/luna/pc/me?aid=386088`

**请求头**：`Cookie: sessionid=<value>`

**响应关键字段**（IDL `GetMyInfoResponse`）：

| 字段 | 含义 |
|------|------|
| `status_code` | `0` 成功；`1000016` 登录失效 |
| `my_info` | 当前用户资料（id、nickname、douyin_id、is_vip、vip_stage、头像等） |
| `my_stats` | 用户统计 |
| `tab_entries` | 「我的」页入口 |
| `free_vip_banner` / `reward_ad_banner` / `me_tab_banners` | 运营位 |
| `play_panel_info` / `me_tab_tool_list` | 播放面板与工具列表 |

本项目 `auth-profile.js` 约定的展示字段：`my_info.id`、`nickname`、`douyin_id`、`is_vip`、`vip_stage`。

**本项目代理**：`POST /api/auth/profile`，body `{ aid?, sessionid }`

## 三、本机 Cookies 登录

### 3.1 原理

汽水 PC 基于 Electron/Chromium，Cookie 库路径固定：

```
%HOMEDIR%\AppData\Roaming\SodaMusic\Network\Cookies
```

只读打开 SQLite，查询：

```sql
SELECT name, value, host_key
FROM cookies
WHERE host_key IN ('.qishui.com', 'qishui.com')
  AND name = 'sessionid'
LIMIT 1
```

实现：`server/utils/sodamusic-cookie.js`。只读，不修改客户端 Cookie 库。

### 3.2 本项目代理

| 本地接口 | Method | 说明 |
|----------|--------|------|
| `/api/auth/one-click-support` | GET | 探测本机 Cookies 是否可读出 sessionid |
| `/api/auth/file-login-support` | POST | 前端上传 Cookies 文件（base64），落盘临时文件后解析 sessionid |
| `/api/auth/auto-login` | GET | 静默读本机 sessionid 并请求 `/luna/pc/me` 校验，返回精简资料 |

**one-click-support 响应**：

| 字段 | 含义 |
|------|------|
| `supported` | 是否可一键登录 |
| `is_windows` | 当前后端是否 Windows |
| `cookie_db_path` | Cookies 库完整路径 |
| `sessionid` | 读到的会话（可能为空） |
| `message` | 不可读原因（非 Windows / 未安装 / 未登录 / 文件占用等） |

**约束**：

- 仅 Windows（后端本身在 `server/index.js` 也限制 win32）。
- 汽水客户端正在运行时 SQLite 可能 locked/EBUSY，需先退出客户端。
- 文件登录会对 `SQLITE_NOTADB` / `SQLITE_CORRUPT` / 空文件 / 占用分类提示。

**注册状态**：`auth-auto-login.js` 文件存在，但当前 `server/apis/index.js` 未挂载该路由；若需要使用需先在 index 中注册。

## 四、SSO 与 token 相关

### 4.1 `/luna/sso/token`

| 项 | 内容 |
|----|------|
| Method | GET |
| query | `code`、`state`、`device_id` |
| 响应 | `status_code`、`status_msg`、`auth_token` |

用于字节 SSO 场景换 token；本项目未代理。

### 4.2 `/luna/token/user/info`

| 项 | 内容 |
|----|------|
| Method | GET |
| query | `token` |
| 响应 | `user`（UserBasic） |

### 4.3 `/passport/token/beat/web/`

出现在 sourcemap 与 BDTicket 默认白名单。属于登录态保活接口，调用需 Cookie + BDTicket 签名。本项目未代理。

## 五、设备与启动

| Method | Path | 用途 | 关键响应字段 |
|--------|------|------|--------------|
| GET | `/luna/device/recent-login` | 本机最近登录用户 | `user_basic` |
| GET | `/luna/launch` / `/luna/pc/launch` | 启动配置 | `device_status`、`boost_setting`、`location`、`invite_code` |

## 六、与本项目关系

| 本项目能力 | 依赖上游 |
|------------|----------|
| 扫码登录 | passport get_qrcode + check_qrconnect |
| 一键登录 | 本机 Cookies SQLite → sessionid → `/luna/pc/me` |
| 文件登录 | 上传 Cookies → 同上 |
| 资料展示 | `/luna/pc/me` |
| 下载接口鉴权 | 所有 `/api/track/*`、`/api/playlist/*`、`/api/video/v2` 均要求 body 带 `sessionid` |

sessionid 只保存在前端/调用方，本地代理不落库；代理转发时通过 `Cookie: sessionid=...` 注入上游请求。
