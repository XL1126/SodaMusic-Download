# 评论、商业化与社交接口

说明汽水音乐评论、分享、VIP/商业化、直播、IM、消息、配置埋点与反馈相关接口。

---

## 一、评论

| Method | Path | 用途 | 鉴权 |
|--------|------|------|------|
| GET | `/luna/pc/comments` | 评论列表 | Cookie |
| GET | `/luna/comments` | 非 PC 列表 | Cookie |
| GET | `/luna/h5/comments` | H5 列表 | Cookie 可选 |
| GET | `/luna/pc/comments/{comment_id}/replies` | 楼中楼 | Cookie |
| GET | `/luna/pc/comment` | 单条评论 | Cookie |
| POST | `/luna/pc/comments/create` | 发表评论 | Cookie |
| POST | `/luna/pc/comments/delete` | 删除评论 | Cookie |
| POST | `/luna/pc/comments/action` | 评论点赞等 | Cookie |
| GET | `/luna/emoticons/recommend` | 评论表情 | Cookie |
| GET | `/luna/atlist` | @ 候选 | Cookie |

### 1.1 列表 ListComments

**请求**：`group_id`、`cursor`、`count`、`group_type`、`image_strategy`、`sort_type`。

**响应**：`comments[]`、`count`、`cursor`、`has_more`、`prompts[]`、`douyin_comment_cnt`。

### 1.2 回复 ListReplies

**请求**：path `comment_id`，query `cursor`、`count`、`image_strategy`、`ab_param`。

**响应**：`reply_infos[]`、`count`、`cursor`、`has_more`。

### 1.3 发表 CreateComment

**body**：`group_id`、`text`、`reply_id`、`reply_to_reply_id`、`reply_to_user_id`、`comment_type`、`group_type`、`hashtags[]`、`text_extra[]`、`image_list[]`。

**响应**：`created_comment`、`comment_type`、`featured_tags`、`comment_label`、`punish_result`、`image_list[]` 等。

### 1.4 动作 CommentAction

**body**：`comment_id`、`reply_id`、`group_id`、`type`、`scene_name`。

**响应**：`liked_comment`。

## 二、分享与短链

| Method | Path | 用途 | 鉴权 |
|--------|------|------|------|
| GET | `/luna/pc/share_info` | 分享信息 | Cookie |
| GET | `/luna/share_info` | 非 PC 分享信息 | Cookie |
| GET | `/luna/share/code/parse` | 分享码解析 | Cookie |
| GET | `/luna/query_zlink` | zlink token 查询 | Cookie |
| GET | `/luna/shorten_zlink` | 生成短链 | Cookie |
| POST | `/luna/share/post_aweme` | 分享到抖音 | Cookie |
| GET | `/luna/share/post_aweme/status` | 分享任务状态 | Cookie |
| POST | `/luna/share/user_list` | 分享目标用户 | Cookie |
| POST | `/luna/pc/count/shared` / `/luna/count/shared` | 分享计数 | Cookie |

### 2.1 share_info

**请求 query**：`item_type`、`item_id`、`extra`、`scene`、`open_anchor_info`（可选）。

**响应**：`share_info`（ShareInfo）。

### 2.2 share/code/parse

**请求 query**：`token`。

**响应**：`header`、`content_img`、`content_text`、`btn_text`、`schema`。

### 2.3 query_zlink

**请求 query**：`token`。

**响应**：`info`（string）。

### 2.4 shorten_zlink

**请求 query**：`zlink_id`、`scheme_string`。

**响应**：`shortened_url`。

本项目 `POST /api/share/resolve` 未走上述 API，而是 GET 分享落地页 HTML 后用正则提取 `track_id` / `video_id`。

## 八、与本项目关系

| 能力 | 是否使用本文接口 |
|------|------------------|
| 曲目/视频下载主链路 | 否（走 track_v2 / video_v2） |
| 分享链接解析 | 当前用 HTML 正则；可选升级为 `/luna/share/code/parse`、`/luna/query_zlink` |
| 下载权限诊断 | 可选 `/luna/commerce/v2/check_download`、mcheck |
| 评论/直播/IM/商业化 | 本项目未对接 |

## 文档说明

基于 SodaMusic PC 3.5.1 / 3.7.0 逆向材料整理，仅供本项目开发者学习研究与本地调试对接使用。
