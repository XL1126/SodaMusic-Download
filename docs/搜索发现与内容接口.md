# 搜索、发现与内容接口

说明汽水音乐搜索、联想、发现页、信息流、专辑、歌手、榜单等浏览类接口。

---

## 一、搜索

| Method | Path | 用途 | 鉴权 | 备注 |
|--------|------|------|------|------|
| GET | `/luna/pc/search/{search_type}` | PC 搜索 | Cookie | search_type 为路径参数 |
| GET/POST | `/luna/search/{search_type}` | 通用搜索 | Cookie | |
| POST | `/luna/h5/search/{search_type}` | H5 搜索（Search2023） | Cookie 可选 | |
| GET | `/luna/pc/sug` | 搜索联想 | Cookie | |
| GET | `/luna/sug` | 非 PC 联想 | Cookie | |
| POST | `/luna/search-block` | 搜索页区块 | Cookie | includes / from_query |
| POST | `/luna/search-categories` | 搜索分类 Tab | Cookie | |
| GET | `/luna/suggest-words/{suggest_type}` | 推荐词 | Cookie | |
| POST | `/luna/playlist/search` | 歌单内搜索 | Cookie | playlist_id + query |
| POST | `/luna/flow/search/{search_type}` | Flow 搜索 | Cookie | |

### 1.1 Search 请求要点

IDL：`SearchRequest`。

| 字段 | 说明 |
|------|------|
| `q` | 查询词 |
| `search_type` | 路径中的类型（由 categories 返回） |
| `cursor` | 分页 |
| `search_id` / `from_search_id` | 搜索会话链 |
| `search_method` / `search_scene` | 来源场景 |
| `debug_params` / `ab_param` | 调试与实验 |
| `scene_name` | 业务场景名 |
| `last_viewed_media` | 上次浏览媒体（相关搜索） |
| `transit` / `limited_free_scene` | 跳转与限免场景 |

**响应**：`result_groups[]`、`extra`、`debug_info`。

### 1.2 Sug

| 字段 | 说明 |
|------|------|
| `q` | 前缀 |
| `sug_scene` / `sug_search_id` | 场景与会话 |

响应：`sugs[]`。

### 1.3 search-categories

响应：`search_category_tabs[]`，每项 `search_type` + `name`。实际搜索 path 中的 `{search_type}` 取自该列表。

## 六、与本项目关系

本项目下载主流程不直接调用 search/feed；解析分享链接得到 `track_id` / `video_id` 后走 track_v2 / video_v2。

若扩展「搜索下载」：

1. `GET /luna/pc/sug` 或 `GET /luna/pc/search/{type}` 拿 track 列表；
2. 用 track_id 调 `/luna/pc/track_v2`；
3. 走现有解密下载链路。

本项目分享解析 `POST /api/share/resolve` 当前是抓取落地页 HTML 提取 ID，**未**使用上游 `/luna/share/code/parse`、`/luna/query_zlink`（见评论商业化与社交文档中的分享接口表）。
