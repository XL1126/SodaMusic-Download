## 二、track_v2（核心）

### 2.1 请求

**路径**：`POST https://api.qishui.com/luna/pc/track_v2?aid=386088&...`

**必须请求头**：

| Header | 值 |
|--------|-----|
| `Cookie` | `sessionid=<value>` |
| `Content-Type` | `application/json; charset=utf-8` |
| `User-Agent` | `LunaPC/3.7.0(452316191)` |
| `X-Helios` | BDMS 签名 |
| `X-Medusa` | BDMS 签名 |
| `X-SS-STUB` | body MD5（大写） |

**body（本项目默认）**：

| 字段 | 示例 | 说明 |
|------|------|------|
| `track_id` | `"7123..."` | 曲目 ID |
| `media_type` | `"track"` | 媒体类型 |
| `queue_type` | `"search_one_track"` | 队列类型 |
| `scene_name` | `"search"` | 场景名 |

IDL `GetTrackV2Request` 还定义了：`limited_free_param`、`need_show_diversion_anchor`、`extra_params`、`scene`、`enable_refresh_api`。

**行为要点**：

- 无 BDMS 签名：HTTP 200，**空 body**。
- 签名与请求绑定：换 track_id 后旧签名无效，仍可能空 body。

**本项目代理**：`POST /api/track/v2`，body：`sessionid`、`track_id`、可选 `media_type`/`queue_type`/`scene_name`。

### 2.2 响应结构

IDL：`GetTrackV2Response`。

| 字段 | 说明 |
|------|------|
| `status_code` | 0 成功 |
| `status_info` | log_id / now / now_ts_ms / status_msg |
| `track` | 曲目元数据 |
| `track_player` | 播放器资源（PlayerInfo） |
| `lyric` | 歌词（TrackLyrics） |
| `risk_result` | 风控结果 |
| `expire_at` | 资源过期时间 |
| `track_wrapper` / `my_artist_stats` | 扩展信息 |

**track 常用子字段**（本项目 `track-download.js` 使用）：

| 字段 | 用途 |
|------|------|
| `track.name` | 曲名 |
| `track.artists[]` | 歌手；`simple_display_name` / `user_info.nickname` / `name` |
| `track.album.name` / `track.album.release_date` | 专辑与发行日（秒级时间戳） |
| `track.song_maker_team.composers/lyricists` | 词曲作者 |
| `track.tags[]` | `first_level_tag` / `second_level_tag` 的 `tag_name` |
| `track.cover` / image 类对象 | `urls[]`、`uri`、`template_prefix` |

### 2.3 媒体资源 video_model

下载资源挂在：

```
track_player.video_model   // JSON 字符串，需二次 JSON.parse
```

解析后结构：

| 字段 | 说明 |
|------|------|
| `video_list[]` | 多音质列表 |
| `video_list[].video_meta.quality` | 品质标识 |
| `video_list[].video_meta.definition` | 清晰度文案 |
| `video_list[].video_meta.size` | 字节大小 |
| `video_list[].video_meta.vtype` | 容器类型 |
| `video_list[].main_url` | 主下载 URL |
| `video_list[].backup_url` | 备用 URL |
| `video_list[].encrypt_info.spade_a` | 加密相关信息 |

实测样本：存在约 5 种音质；资源本体可能加密（需本项目解密链路）。

本项目提取兼容路径（防字段改名）：

1. `track_player.video_model`
2. `track_player.audio_model`
3. `track.video_model`
4. `data.track_player.video_model`
5. `data.tracks[0].video_model`
6. `track.audio_model`

媒体拉取时本项目使用 UA：`libcurl-agent/1.0`。

### 2.4 歌词

无独立 lyric API。歌词在 track_v2（或旧版 track，`includes: ['lyric']`）的 `lyric` 字段中。本项目 `server/utils/lyric-converter.js` 负责格式转换。

## 三、video_v2

### 3.1 请求

**路径**：`POST https://api.qishui.com/luna/pc/video_v2`

**body（本项目默认）**：

| 字段 | 示例 |
|------|------|
| `video_id` | 视频 ID |
| `type` | `ugc_video` |
| `scene_name` | `library` |
| `queue_type` | `favorite_track_playlist` |

IDL `GetVideoV2Request`：`video_id`、`type`、`enable_refresh_api`、`enable_dash`、`scene_name`、`queue_type`。

### 3.2 响应

IDL：`GetVideoV2Response`。

| 字段 | 说明 |
|------|------|
| `video` | 视频元数据 |
| `video_player` | PlayerInfo（含播放/下载 URL 结构） |
| `media_stats` | 统计 |
| `risk_result` | 风控 |
| `expire_at` | 过期 |
| `player_infos` | 多份播放信息 |

`Video` include 常量：`video`、`video_player`、`media_stats`、`risk`。

无签名时实测可能返回 `status_code=1000062`。

**本项目代理**：`POST /api/video/v2`。

## 四、media-player

**路径**：`GET/POST /luna/pc/media-player`

**请求要点**：

| 字段 | 说明 |
|------|------|
| `vid` | 视频 ID |
| `media_type` | 媒体类型 |
| `media_id` | 媒体 ID |
| `queue_type` | 队列类型 |
| `limited_free_param` | 限免参数 |
| `enable_refresh_api` / `enable_dash` | 刷新 / DASH |
| `scene_name` | 场景 |

响应：`player_info` 或 `player_infos[]`（`media.PlayerInfo`）。

track_v2 未直接给出可播 URL 时，可用 media-player 补拉。

## 五、mcheck 可用性

**路径**：`POST /luna/pc/mcheck`

**body 要点**：`media_list[]`（Media：id + type）、`scene`、`scene_name`、`queue_type`、`limited_free_param_map`。

**响应**：`media_status[]`，单条含：

| 字段 | 说明 |
|------|------|
| `id` / `type` | 媒体标识 |
| `status` | 业务状态 |
| `download_status` | 下载权限状态 |
| `share_status` / `sharable_platforms` | 分享权限 |
| `limited_free_info` | 限免信息 |
| `digital_track_info` | 数字专辑信息 |
| `risk_result` | 风控 |

本项目当前批量下载直接依赖 track_v2；若需预检版权/会员限制，可加 mcheck。

## 六、与本项目关系

```
playlist/detail  →  track_id 列表
       ↓
POST /api/track/v2  →  /luna/pc/track_v2（BDMS 签名）
       ↓
track_player.video_model → video_list[].main_url
       ↓
GET main_url（加密媒体）→ 本地解密 → FLAC/M4A
```

| 本项目接口 | 上游 | 说明 |
|------------|------|------|
| `POST /api/track/v2` | `/luna/pc/track_v2` | 透传曲目 JSON，带 BDMS |
| `POST /api/track/download-encrypted` | track_v2 + 媒体 URL | 解密后附件下载 |
| `POST /api/video/v2` | `/luna/pc/video_v2` | 视频元数据 |
| `POST /api/video/download` | 媒体直链 | 流式转发 |
| `POST /api/video/download-audio` | 媒体直链 | 抽音频转 MP3 |

签名初始化 deviceId 使用逆向样本值 `2117006317868281`；UA 固定 `LunaPC/3.7.0(452316191)`。
