# 用户、歌单与收藏接口

说明汽水音乐 PC「我的」相关接口：当前用户、自建/收藏歌单、媒体收藏、最近播放、隐私、关注与黑名单。

PC 路径优先使用 `/luna/pc/*`；部分能力仅有 `/luna/*` 版本。

---

## 一、当前用户

| Method | Path | 用途 | 鉴权 | 备注 |
|--------|------|------|------|------|
| GET | `/luna/pc/me` | 当前登录用户资料 | Cookie | 主接口 |
| GET | `/luna/me` | 同上（非 PC 前缀） | Cookie | |
| POST | `/luna/me` | 更新我的资料 | Cookie | `UpdateMyInfo` |
| GET | `/luna/h5/me` | H5 简要信息 | Cookie 可选 | `GetMyBriefInfo` |
| GET | `/luna/h5/users/{user_id}` | H5 用户简要 | Cookie 可选 | |
| GET | `/luna/pc/users/{user_id}` | 他人主页 | Cookie | `GetUserInfo` |
| GET | `/luna/users/{user_id}` | 同上非 PC 前缀 | Cookie | |
| GET | `/luna/user/info` | 用户信息（query user_id） | Cookie | |
| GET | `/luna/user_brief/info` | 用户简要 V2 | Cookie | sec_uid |
| GET | `/luna/pc/users/{user_id}/follower` | 粉丝列表 | Cookie | cursor 分页 |
| GET | `/luna/pc/users/{user_id}/following` | 关注列表 | Cookie | |
| POST | `/luna/user/settings` / GET 同路径 | 用户设置读写 | Cookie | `UpdateLunaUserSettings` / `GetLunaUserSettings` |

### `/luna/pc/me` 响应要点

IDL：`GetMyInfoResponse`。

| 字段 | 说明 |
|------|------|
| `status_code` | 0 成功；1000016 登录失效 |
| `my_info` | id / nickname / douyin_id / is_vip / vip_stage / medium_avatar_url 等 |
| `my_stats` | 统计 |
| `redeem_freevip_info` | 免费 VIP 兑换信息 |
| `tab_entries` / `me_tab_banners` / `me_tab_tool_list` | 「我的」页结构 |
| `play_panel_info` | 播放面板 |

**本项目**：`POST /api/auth/profile` 代理此接口。

| GET/POST | `/luna/playlist/detail` | 非 PC 前缀详情 | Cookie | |

### 歌单列表响应（GetMyPlaylistsResponse）

| 字段 | 说明 |
|------|------|
| `playlists` | Playlist 数组（id、title、count_tracks、owner 等） |
| `total_num` | 总数 |
| `next_cursor` / `has_more` | 分页 |

**本项目**：`POST /api/me/playlists` → `/luna/pc/me/playlist`，query 带 `getPcQuery()`。

### 歌单详情请求要点

`GetPlaylistDetailRequest` 常用字段：

| 字段 | 说明 |
|------|------|
| `playlist_id` | 必填 |
| `cursor` | 分页游标，首页空串 |
| `count` | 每页条数（本项目默认 15） |
| `user_id` / `sec_uid` | 他人歌单可选 |
| `only_need_media` / `only_need_media_id` | 只要媒体标识 |
| `sort_type` | 排序 |
| `session_id` / `ab_param` | 会话与实验参数 |

响应：`has_more`、`next_cursor`、`playlist`、`tracks`、`media_resources`、`session_id`。

**本项目**：`POST /api/playlist/detail`，body：`sessionid`、`playlist_id`、`cursor`、`count`。

## 三、歌单内曲目维护

| Method | Path | 用途 | 请求要点 |
|--------|------|------|----------|
| POST | `/luna/pc/me/playlist/media/append` | 批量加媒体 | playlist_id + media[] |
| POST | `/luna/me/playlist/track/append` | 批量加曲目 ID | playlist_id + track_ids[] |
| POST | `/luna/pc/me/playlist/media/delete` | 删除媒体 | playlist_id + media[] |
| POST | `/luna/me/playlist/track/delete` | 删除曲目 ID | playlist_id + delete_track_ids[] |
| POST | `/luna/me/playlist/media/sort` | 媒体排序 | playlist_id + media[] |
| POST | `/luna/me/playlist/track/sort` | 曲目排序 | playlist_id + track_ids[] |

删除曲目响应会回传 `delete_track_ids`、`playlist_id`、`url_cover`、更新后的 `playlist`。

## 四、收藏

### 4.1 混合收藏列表

| Method | Path | 用途 | 鉴权 |
|--------|------|------|------|
| GET | `/luna/pc/me/collection/mixed` | 我的混合收藏列表 | Cookie |
| GET | `/luna/me/collection/mixed` | 非 PC 路径 | Cookie |
| GET | `/luna/pc/user/collection/mixed` | 他人混合收藏 | Cookie |

请求 query：`cursor`、`count`、`item_types`（可选过滤）。

**本项目**：`POST /api/me/collection/mixed`。响应约定含 `mixed_collections[]`（`item_type` + 对应 playlist/track 等）与 `total_num`。

### 4.2 分类收藏读写

| Method | Path | 用途 | body 要点 |
|--------|------|------|-----------|
| POST | `/luna/pc/me/collection/track` | 收藏曲目 | track_ids[] |
| POST | `/luna/me/collection/track/delete` | 取消曲目收藏 | track_ids[] |
| POST | `/luna/pc/me/collection/playlist` | 收藏歌单 | playlist_ids[] |
| POST | `/luna/pc/me/collection/playlist/delete` | 取消歌单收藏 | playlist_ids[] |
| POST | `/luna/pc/me/collection/album` | 收藏专辑 | album_ids[] |
| POST | `/luna/pc/me/collection/album/delete` | 取消专辑收藏 | album_ids[] |
| POST | `/luna/pc/me/collection/artist` | 收藏歌手 | artist_ids[] |
| GET | `/luna/me/collection/artist` | 歌手收藏列表 | cursor/count |
| POST | `/luna/pc/me/collection/artist/delete` | 取消歌手收藏 | artist_ids[] |
| POST | `/luna/pc/me/collection/media` | 统一媒体收藏 | media[] + scene + collect_action |
| POST | `/luna/pc/me/collection/media/delete` | 取消媒体收藏 | media[] |

`CollectActionType`：`0` Unknown、`1` ClickHeartFromPlayer、`2` DoubleClickFromPlayer、`3` ClickFromBackground、`4` Other。

注意：`/luna/pc/me/collection/media`、`/luna/pc/me/collection/playlist`、`/luna/pc/me/collection/album`、`/luna/pc/me/collection/artist`、`/luna/pc/me/follow` 在 BDTicket 默认白名单内，PC 客户端对这些路径额外做零信任加签。

## 五、最近播放

|--------|------|------|
| GET | `/luna/pc/me/recently-played-media` | 最近播放媒体 |
| POST | `/luna/pc/me/recently-played-media` | 追加最近播放 |

## 八、与本项目关系

| 本项目代理 | 上游 | 用途 |
|------------|------|------|
| `POST /api/me/playlists` | `/luna/pc/me/playlist` | 列出自建歌单供下载选择 |
| `POST /api/me/collection/mixed` | `/luna/pc/me/collection/mixed` | 列出收藏歌单等 |
| `POST /api/playlist/detail` | `/luna/pc/playlist/detail` | 分页拉取歌单曲目，驱动批量下载 |

下载前的曲目遍历依赖 `playlist/detail` 的 `media_resources` / `tracks`，再对每条 track 调用 track_v2（见曲目文档）。
